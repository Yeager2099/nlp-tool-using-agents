# Tool-Using Language Agents and Error Recovery

**Course:** CIS 5300 / HW10  
**Artifact type:** Course project / coursework

## Overview

Implemented a ReAct-style agent with structured calls to calculator, information retrieval, and weather tools. Added bounded retries for failed calls and evaluation routines for single-step and multi-step tasks.

## Guiding question

How can a language agent recover from tool failures and complete multi-step tasks?

## Methods and technical scope

Python; structured tool calling; ReAct; bounded retries.

## Evaluation and analysis

Evaluate task completion and inspect tool-call traces, recovery behavior, and failure modes. External tool behavior can change.
